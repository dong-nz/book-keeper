# Release v0.0.9 — November 12, 2026

This release adds **EPUB books**. The app now manages books exactly like it manages PDFs — import them, tag them, star them, search them, see their covers — and it **reads books inside itself**, in their own reading window, the way it reads PDFs.

## What changed for you

**Books join your library**

- The app accepts **EPUB files everywhere it accepts PDFs**: the file picker shows both, **Import folder** adds both kinds from a directory, and drag-and-drop takes both. Any other file type is still skipped with a notice.
- Because the app now handles two file types, the import actions are named plainly again: **Import files** and **Import folder** (the keys are unchanged: `Ctrl+I` for files, `Ctrl+O` for a folder).
- A book is treated exactly like a document everywhere else: tags, favorites, the Reading collection, search, renaming its file, relinking when a file moved. A book's title and author are read from the book's own properties when it has them; its cover comes from the book's own cover image. Books sit in the list next to PDFs with no special mark — you tell them apart by the extension in the filename.

**Reading books inside the app**

- Opening a book — double-click, `Enter`, or **Open** — shows it in its own reading window. **Open in external viewer** hands it to your computer's other book application instead.
- A book is one continuous, flowing text that adapts to the window's width and to the text size you choose; you read it by scrolling. The book's own fonts, styles, and illustrations appear as the book intends, and **selecting and copying text works**. Links inside the book jump to their target in the same window; a link that points outside opens in your browser.
- The strip at the bottom holds everything for working with a book: its **contents** (the book's own table of contents, or a chapter list when it has none), your **position** as a percentage with a *Go to position* field, and **text size** controls — the size you pick is remembered for every book.
- Keys while reading a book: `↑` `↓` scroll, `PageUp` `PageDown` a screen, `Home` `End` jump to the start or end, `Esc` closes the contents panel first if it's open, otherwise the window.
- Books open quickly: measured on the test machine, a book with a 1 MB chapter shows its first readable text about 0.3 seconds after opening.

**Fixes you reported**

- **The reader window's controls no longer squeeze together** when a document has a very long title — the title gives way before the buttons do.
- **The PDF reader no longer flashes at open** — the page now fades in over its preview image instead of appearing after a blank moment.

## What this version does not do yet

- **Books that are protected (DRM) can't be read inside the app** — the window says so plainly, and you can still open them in an external viewer.
- The app does not remember where you stopped reading a book — the same gap that exists for PDFs. There are no bookmarks, highlights, or notes inside a book, no page numbers (position is a percentage), and no search inside a book's text.
- A protected PDF's title and author are still not read from the file, as before.
- Several improvements you asked for are planned for the next release: a **side-by-side horizontal reading mode for PDFs**, **pinning the contents panel** in the reader, a **settings menu in the reader window**, **bigger covers in list view**, and **automatic app updates**.
- Windows only, as before — macOS and Linux builds come with a later release.

## Known issues

None known at release time. One note on how this release was verified: the full regression pass that normally runs after every release was **skipped for this release at the user's request**. Verification instead covered everything this release changed — automated tests for importing and for reading both document types (191 checks, all passing) and a manual review of the app. What that leaves unexamined is everything *else* — if anything that used to work no longer does, please report it.
