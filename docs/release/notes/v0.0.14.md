# Release v0.0.14 — November 20, 2026

This release refines the parts of the app you touch most: editing a document's tags is now a **picker** instead of a long checkbox list, an **always-visible strip** shows and removes your active filters, the tags window opens ready for typing, **tag counts stay correct after deletions**, the Select switch gets a proper selection icon and **switching it off now ends the selection**, and the "open the folder" action in Details becomes a small **folder button on the path**.

## What changed for you

**Tags in the Details dialog: a picker**

- The tags section is rebuilt. Your document's current tags show as **chips**, each with an × that removes it right away. Below them, **Add tag** opens a searchable list: type to narrow it, click a name to add it (click again to take it off), and the tags already on the document are clearly marked in the list.
- A name that doesn't match any existing tag offers **Create "…"** — press Enter or click it, and the new tag is created and added on the spot. Up and down arrows move through the list; Enter works on the highlighted row. Escape closes just the tag picker — your edits stay.
- **Your edits are safe when a tag is created on the spot.** A title you typed, notes you drafted, tags you picked — creating a new tag no longer resets the editor. (Before this update, creating a tag while editing could quietly throw away your pending changes; that's fixed.)
- Saving works exactly as before: the dialog keeps your changes until you press Save, and only then writes them.

**A strip above the document list shows what's filtering**

- When any Browse filter is active — a Favorites / Reading / Missing view, or one or more tags — a strip appears directly above the document list: one chip per active filter, the view first, each with an × that removes just that filter. **Clear all** removes them all at once.
- When the window is too narrow for every chip, the extra ones collapse into a **+N** chip; opening it lists the hidden filters, each removable there too.
- Search terms never appear in the strip — search keeps working exactly as it always did. The Browse menu is unchanged: it's still where you choose filters.

**The tags window is quicker to use, and counts stay fresh**

- Opening *Browse ▸ Manage tags* puts the cursor straight in the **New tag** field — you can start typing a name immediately.
- After you delete documents — one or many — the counts in *Browse ▸ Tags* and in the tags window match reality immediately. Before this update they could keep counting a document you had just deleted until something else refreshed them. The same fix covers bulk tag changes from the selection bar.

**Select switch: new icon, and switching off ends the selection**

- The Select button now shows a **selection-box icon** — corner brackets with handles — instead of the old checked-square. Its name, tooltip, keyboard path and pressed look are otherwise the same.
- **Switching the mode off now clears the selection**: whatever you had selected is released, the actions bar disappears, and the rows return to ordinary browsing. Switching it back on starts with a clean selection. Selecting while browsing (`Space`, `Ctrl`-click, `Shift`-click) and the actions bar itself are unchanged.

**Details: the folder action is a small button on the path**

- The document's path row now carries the *Open containing folder* action as a **folder icon button** at the end of the path, replacing the text button at the bottom of the dialog. Same action — your file manager opens with the file selected — and it still appears only when the file is present. The item in the right-click menu is unchanged.

**Release pages on GitHub now carry the release notes**

- The download page for each published version now shows that version's release notes as its description, instead of an empty page. Pre-release test builds get a short line saying what they are.

## What this version does not do yet

- Tags still can't be changed directly on a row or card — the picker is in the Details dialog, and bulk changes stay in the selection bar's tag tool.
- The strip only shows and removes filters; choosing them stays in the Browse menu. Search filters are never part of the strip.
- Creating a tag from the picker has no undo — a wrong name is fixed in the tags window (rename or delete).
- Deleting a tag still asks for confirmation and detaches it from every document; there is no tag merging yet.

## Known issues

- The installers still carry no purchased store certificate, so Windows may show an *"Unknown publisher"* warning on first run (**More info → Run anyway**) and a Mac shows the usual "downloaded from the Internet" notice (right-click → **Open** once).
- If your Windows machine carried an old whole-device install of the app, its stale entry stays in *Settings → Apps & features* until you remove it once; the live install is the one under your own account.
- The release-page notes and the download-pipeline behavior are confirmed on the published release itself; if anything looks off there, please report it.
